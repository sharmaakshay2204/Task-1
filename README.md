 🎵 Musico

Musico is a Spotify-inspired music streaming website built using HTML and CSS.

 ✨ Features

* 🎵 Music and artist cards
*  Album covers
*  User profile section
*  Search bar
*  Play buttons
*  Spotify-style bottom music player
*  Responsive design
*  Dark-themed interface

 Technologies Used

* HTML5
* CSS3
